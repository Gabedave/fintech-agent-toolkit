# Historical evidence

Prefer evidence closest to the decision:

1. Explicit decision record or accepted ticket requirement
2. Pull-request description and resolved review discussion
3. Commit message plus the exact diff it introduced
4. Contemporaneous operational evidence or incident record
5. Current code and tests
6. Inference from surrounding context

Current code proves behavior, not original intent. A later comment may describe the present rationale but should not be attributed to the original author without corroboration.

For conflicting sources, report the conflict and prefer the source that is explicit, contemporaneous, and authoritative for the boundary. Do not turn a private discussion into a durable policy unless the repository or ticket establishes it.
