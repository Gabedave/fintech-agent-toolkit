# Improvement proposal

For each proposal report:

- **Observed evidence:** the task, failure, repetition, or measurable cost.
- **Root workflow cause:** why existing guidance or automation did not prevent it.
- **Proposed artifact:** exact test, script, skill, instruction, CI, or documentation location.
- **Expected effect:** observable improvement and how to measure it.
- **Trade-off:** maintenance, runtime, Actions, token, or human-review cost.
- **Scope boundary:** situations where the rule must not apply.
- **Disposition:** accept, reject, backlog, or needs more evidence.

One task can justify a local guard. Shared policy normally requires a recurring pattern or a sufficiently severe risk with a clear prevention mechanism.
