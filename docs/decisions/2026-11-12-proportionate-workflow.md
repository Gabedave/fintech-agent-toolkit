# Proportionate workflow execution

Status: Proposed

## Context

Shared instructions repeated authority records, loaded unrelated playbooks and could expand focused work into repository-wide audits. Verification results also lacked explicit reuse ownership. The requested repair reduces this overhead while preserving financial proof and evidence standards.

## Decision

Keep one inspectable authorization ledger and report deltas, except when a required structured output needs all fields. Status-only reads use authoritative subject/revision state; diagnosis and implementation retain the source model. Disclose individual playbooks through one common policy/index. Scope verifier audits by affected dependencies, expanding for shared changes, uncertainty or systemic drift. The review gate owns one combined-tree check, reusable only with unchanged, rechecked identities and inputs.

Offer explicit targeted development smoke runs. Preserve the full exact-candidate team-ready/release suite, broad-routing coverage and required review-quality pilot. Targeted results never satisfy full qualification or erase adverse history. Installation and external-model authorization remain independent.

## Alternatives and consequences

Keeping the previous blanket workflow avoids selection mistakes but spends context and execution on unrelated work. Removing proof gates would be cheaper but would lose the requested safeguards. Scoped execution with conservative invalidation retains those gates while reducing duplication. More reference files require link/reachability checks; narrow test selection requires a recorded impact rationale and retains full coverage before readiness.

## Verification and reconsideration

Use deterministic routing and negative controls, generator/provenance tests, unchanged financial/evidence checks, and later authorized model evaluation. Static checks do not establish model compliance or cost savings. Reconsider if scoped audits miss dependent failures, partial runs are mistaken for qualification, or evidence is reused after its inputs change. Human acceptance remains pending.
